# BOB Routine

Native iPhone routine companion built with SwiftUI.

## V1
- Adaptive Day: start the day when the user actually wakes up
- Five daily missions
- Water counter
- Normal workout and Mager Mode
- Progress area
- Local notification permission
- Local-first design

The Xcode project is generated from `project.yml` using XcodeGen. Codemagic configuration is in `codemagic.yaml`.
